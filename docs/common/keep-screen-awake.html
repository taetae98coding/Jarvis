사용자 지시

화면 꺼짐 방지 토글을 기능 그리드에 넣어라. 토글이 켜져 있으면 어느 화면에 있든 화면이 꺼지지 않아야 하고, 앱을 완전히 껐다 켜도 설정이 남아야 한다.

커밋 503bff1에서 복원.

Compose Multiplatform이 제공하는 Modifier.keepScreenOn()을 쓰고, 직접 만든 expect/actual은 걷어내라. 데스크톱은 macOS만 지원한다.

커밋 3df7b5d "Use Compose's Modifier.keepScreenOn and drop desktop's non-macOS paths"에서 복원.

요구사항

  1. R1. 기능 그리드에 "화면 꺼짐 방지" 토글 카드가 있다. 기본값은 꺼짐이다.
  2. R2. 토글이 켜져 있고 앱이 화면에 떠 있는 동안 OS의 유휴 화면 꺼짐이 일어나지 않는다.
  3. R3. 효과는 특정 화면의 수명에 묶이지 않는다. 화면을 옮겨 다녀도 유지된다.
  4. R4. 토글 값은 설정 영구 저장을 통해 앱을 껐다 켜도 복원된다.
  5. R5. 토글을 끄면 즉시 해제된다.
  6. R6. 별도 권한 요청 없이 동작한다.
스코프에서 뺀 것 앱이 종료되거나 백그라운드로 내려간 뒤에도 화면을 켜 두는 것. 이 기능의 범위가 아니고, 화면 꺼짐 방지 (시스템 전역)로 분리했다. Android만 가능하다.

Compose Multiplatform 1.12가 androidx.compose.ui.keepScreenOn()을 commonMain에 제공하므로 직접 구현하지 않는다. 이 modifier는 레퍼런스 카운팅을 한다. 같은 효과를 요청하는 곳이 여럿이어도 마지막 하나가 사라질 때까지 풀리지 않아서, 예전 expect/actual이 onDispose { keepScreenOn = false }로 다른 요청자를 지워 버리던 문제가 없다.

internal fun Modifier.keepScreenAwake(enabled: Boolean): Modifier =
    if (enabled) keepScreenOn() else this

R3을 위해 App()의 루트 Surface에 붙인다. 화면 전환은 그 아래에서 일어난다.

예외는 데스크톱이다. Compose Multiplatform 1.12.0의 PlatformContext.setKeepScreenOnEnabled는 본문이 빈 기본 구현이고 이를 오버라이드하는 Swing/AWT 구현이 없어서, JVM에서는 modifier가 아무 일도 하지 않는다. 그래서 PlatformIdleInhibitor(enabled) expect/actual을 나란히 두고 JVM actual만 실제 동작을 갖는다. 나머지 세 타깃은 = Unit이다. CMP가 데스크톱 경로를 구현하면 이 expect/actual은 통째로 걷어낸다.

R2(실제로 화면이 안 꺼지는지)는 자동 테스트로 검증하지 않는다. OS의 유휴 타이머를 테스트 안에서 관찰할 방법이 없다. Modifier.keepScreenOn()이 플랫폼 API를 부르는 것은 Compose 쪽 책임이고, JVM의 caffeinate는 개발 머신에서 수동으로 확인했다.

한계

  • 앱이 떠 있는 동안만 유효하다. Android FLAG_KEEP_SCREEN_ON은 윈도우가 보이는 동안만, iOS idleTimerDisabled는 foreground인 동안만 유효하고 시스템이 회수한다. Android의 SCREEN_BRIGHT_WAKE_LOCK은 API 17에서 deprecated된 뒤 화면을 켜 두지 못하며 foreground service로도 우회할 수 없고, iOS에는 해당 API 자체가 없다. 그래서 유지되는 것은 설정값이고, 효과는 앱이 다시 떠 있을 때 재적용된다. 앱 권한이 아니라 시스템 설정을 바꿔서 이 한계를 넘는 경로는 시스템 전역 토글에 있고, Android에서만 열린다.
  • 실패를 알 수 없다. JVM에서 caffeinate가 없거나, Web에서 브라우저가 wake lock을 거부해도 토글은 켜진 상태로 보인다.
  • Compose 밖에서 같은 플랫폼 API를 직접 건드리면 Compose의 카운트와 어긋난다. 지금은 그런 코드가 없다.
