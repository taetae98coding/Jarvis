패널 줄의 버튼을 아래 줄로

왼쪽 패널 목록의 한 줄에서 +·✎·✕ 버튼과 Claude 상태 표시를 이름 옆이 아니라 글자 아래 따로 된 줄로 내려, 이름이 목록 폭을 다 쓰게 한다.

사용자 지시

왼쪽 사이트 탭에서 버튼들과 title이 한줄로 표시되니까 title이 매우 짤려. 버튼들은 다른줄에 표시하도록 수정해줘.

2026-09-25 대화. "왼쪽 사이트 탭" 은 터미널 화면 왼쪽의 패널 목록(패널)으로, "버튼들" 은 패널 줄의 + ("워크트리 추가", 워크트리)·✎ ("이름 바꾸기")·✕ ("패널 닫기")로, "title" 은 패널 이름으로 읽었다.

local main rebase 진행하면 상태 표시하는 것도 한줄로 표시하도록 됐을꺼야 이것도 줄 바꿔서 표시하도록 수정해줘.

2026-09-25 대화. main 에 먼저 들어간 Claude 상태 표시가 이름 칸 바로 오른쪽, 버튼 앞에 있어 이름 폭을 또 나눴다. "줄 바꿔서" 는 표시도 이름 아래의 버튼 줄로 내리는 것으로 읽었다(R6).

이 지시로 패널·워크트리 문서의 "패널 줄" 모양이 바뀐다. 두 문서의 그림에서 이름 옆에 그린 + ✎ ✕ 는 이 문서대로 아래 줄에 있다고 읽는다. 버튼이 보이는 조건과 누를 때의 동작은 그 문서들 그대로다.

요구사항

  1. R1. 패널 줄의 버튼(+·✎·✕ 중 그 줄에 있는 것)은 이름·브랜치 줄·폴더 줄과 다른 줄, 그 글자들 아래에 놓인다. 버튼 줄은 오른쪽 끝에 붙고 순서는 + · ✎ · ✕ 다.
  2. R2. 이름 글자는 버튼과 폭을 나누지 않는다. 이름은 줄의 왼쪽 여백(워크트리 줄은 브랜치 아이콘)부터 오른쪽 여백까지 쓰고, 그래도 넘치면 옆으로 흐른다(뒤따른 글자 흐르게 지시. 그 전에는 끝을 말줄임했다).
  3. R3. 버튼 줄의 빈 자리를 눌러도 글자를 누른 것처럼 그 패널이 선택된다. 버튼을 누르면 버튼 동작만 하고 선택은 바뀌지 않는다(이전과 같다).
  4. R4. 이름을 바꾸는 동안에는 이름 자리에 입력 필드가 오고 버튼 줄은 없다(이전과 같다).
  5. R5. 선택·hover·눌림 배경은 버튼 줄까지 포함한 줄 전체에 그려진다.
  6. R6. Claude 상태 표시가 있는 줄에서 표시는 이름과 같은 줄이 아니라 버튼 줄의 왼쪽 끝에 있다. 표시 아이콘은 이름 첫 글자(워크트리 줄은 브랜치 아이콘)와 같은 세로선에 온다. 이름을 바꾸는 동안에는 그 줄에 버튼 없이 표시만 남고, 표시가 없으면 줄도 없다(R4).
스코프에서 뺀 것
  • Claude 상태 표시를 이름 앞(왼쪽)에 두기. 워크트리 줄의 브랜치 아이콘과 자리가 겹치고, 이름 폭을 다시 나눈다.
  • 버튼을 hover·선택일 때만 보이기. 지시는 "다른줄에 표시" 이고, 터치 기기(Android)에는 hover 가 없다.
  • 목록 폭(200dp) 바꾸기·끌어서 폭 조절. 지시에 없다.
  • 이름을 여러 줄로 감기. 버튼을 내린 것으로 이름이 쓸 폭은 충분히 늘고, 줄 높이가 이름마다 달라지지 않는 편이 목록을 훑기 쉽다.

항목값
줄세로로 쌓는다: 글자 묶음(워크트리 줄은 브랜치 아이콘 + 글자 묶음) → 버튼 줄. 줄 전체에 TerminalPanelItemDefaults.style 배경. 글자 묶음과 버튼 줄의 빈 자리가 선택 클릭을 받는다
글자 묶음이름·브랜치 줄·폴더 줄. 여백은 왼쪽 spacing.m(워크트리 줄은 아이콘 뒤 spacing.xs), 오른쪽 spacing.xs, 위 spacing.s. 아래는 버튼 줄이 있으면 0(버튼의 여백이 대신한다), 이름 입력 필드일 때는 spacing.s
버튼 줄Row, 줄 폭 전체: Claude 상태 표시 → Spacer(weight(1f)) → 버튼. 왼쪽 여백은 보통 줄 spacing.m - spacing.s, 워크트리 줄 spacing.m — 표시 칸의 안쪽 여백(spacing.s)을 빼서 아이콘이 이름·브랜치 아이콘과 세로로 맞는다. 버튼 모양·contentDescription·보이는 조건은 이전과 같다(iconSize.small 아이콘, 둘레 spacing.s)
테스트 태그바뀌지 않는다. terminal:panel:<id>(줄 전체), terminal:panel-rename:<id>, terminal:panel-close:<id>, terminal:new-worktree:<id>, terminal:panel-claude-status:<id>:<tabId>(뒤따른 Claude 상태 R4 로 표시마다)

공통 구현

UI
feature/terminal/ui/src/commonMain/.../TerminalPanelList.kt 의 TerminalPanelItem — 바깥을 Row 에서 Column 으로 바꾸고, 첫 줄(아이콘 + 글자 묶음 또는 입력 필드)과 버튼 줄을 쌓는다. 선택 클릭은 글자 묶음과 버튼 줄에 따로, 같은 interactionSource 로 붙인다(R3·R5). 버튼은 자기 clickable 이 있어 버튼 줄의 클릭을 받지 않는다
상태
해당 없음. 모델·ViewModel 은 바뀌지 않는다
공급
해당 없음. expect 가 없다
결정: 선택 클릭은 줄 전체가 아니라 글자 묶음과 버튼 줄에 따로 붙인다 바깥 Column 하나에 clickable 을 붙이면 그 노드가 semantics 를 합쳐(mergeDescendants) 이름 글자와 브랜치 아이콘(terminal:worktree-panel:<id>)이 줄 노드 안으로 사라진다. 이전처럼 글자 묶음이 이름·브랜치·폴더를 합친 노드로 남고 아이콘은 따로 남도록, 두 자리에 나눠 붙였다. 브랜치 아이콘 자리는 이전처럼 눌러도 아무 일도 없다.
결정: 버튼 줄은 오른쪽 끝에 붙이고 늘 보인다 이전 자리(줄 오른쪽)와 같은 쪽이라 손이 가는 자리가 그대로이고, 이름 첫 글자와 겹쳐 읽히지 않는다. 왼쪽 정렬은 워크트리 줄의 들여쓰기와 버튼 시작점이 어긋나 줄마다 버튼 자리가 달라 버렸다. hover 때만 보이기는 터치에서 버튼을 찾을 수 없어 버렸다.
