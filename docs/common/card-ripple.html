사용자 지시

지금 card ripple이 사각형 형태야 카드 모양에 맞게 ripple 퍼지도록 수정해줘.

2026-09-22 대화.

요구사항

  1. R1. 카드를 누르는 동안 나타나는 물결은 카드의 모서리 둥글기(JarvisCardDefaults.shape) 바깥으로 넘지 않는다. 모서리 네 곳에서 사각형 귀퉁이가 보이면 안 된다.
  2. R2. 누를 수 있는 카드는 종류를 가리지 않고 같은 규칙을 따른다. 토글 카드(toggleable)와 클릭 카드(onClick) 모두.
  3. R3. 물결을 카드 모양으로 자르면서 카드의 배경색·글자 위치·클릭 영역이 달라지지 않는다. 카드 어디를 눌러도 여전히 눌린다.
스코프에서 뺀 것 물결 색·반경·지속 시간을 바꾸는 것. Material 3 기본값을 그대로 쓴다. 카드가 아닌 컴포넌트(버튼, 리스트 항목)는 각자의 기본 모양이 이미 맞아서 건드리지 않는다.

화면·동작

항목값
대상기능 그리드의 모든 카드 — 화면 꺼짐 방지, 시스템 전역 화면 꺼짐 방지, 에뮬레이터
누를 때손가락·포인터가 닿은 지점에서 물결이 번지고, 카드의 둥근 모서리에서 잘린다
뗄 때물결이 사라지고 토글/클릭 동작이 일어난다. 동작 자체는 이 문서에서 바뀌지 않는다
비활성 카드물결이 생기지 않는다(enabled = false). 시스템 전역 화면 유지 카드가 지원되지 않는 플랫폼에서 그렇다
테스트 태그기존 태그를 그대로 쓴다. 이 기능은 태그를 더하지 않는다

공통 구현

원인은 물결을 그리는 자리다. Card는 내부 Surface가 자기 shape로 내용을 자르는데, Modifier.toggleable을 Card의 modifier 인자로 넘기면 그 modifier는 Surface의 클립보다 바깥에 놓인다. 물결은 클립을 받지 않는 자리에서 그려지고, 결과가 사각형이 된다.

토글 카드
ui/component/ToggleFeatureCard.kt — modifier.clip(JarvisCardDefaults.shape).toggleable(…). 클립을 toggleable보다 먼저 두어 물결이 같은 모양으로 잘리게 한다
클릭 카드
designsystem/component/JarvisCard.kt 의 JarvisCard(onClick = …) — 안에서 Material 3의 Card(onClick = …) 오버로드를 부른다. 에뮬레이터·터미널 카드와 기기 줄이 쓴다. 클릭과 물결이 Surface 안쪽에서 처리되어 이미 shape로 잘린다. 따로 클립하지 않는다
공급
없음. 전부 commonMain 의 Compose 코드이고 expect 선언이 필요 없다
결정: 카드 바깥에서 자른다 후보는 셋이었다.
  • 채택. Modifier.clip(JarvisCardDefaults.shape)를 toggleable 앞에 둔다. 한 줄이고 카드 구조를 건드리지 않는다. 카드의 기본 그림자가 0dp(CardDefaults.cardElevation)라 클립으로 잃는 것이 없다.
  • 카드 안쪽 Column에 toggleable을 단다. 물결은 Surface 클립을 받아 맞게 잘리지만, 시맨틱(Role.Switch)이 카드가 아니라 내용에 붙어 테스트 태그가 가리키는 노드와 토글 노드가 갈린다. 버렸다.
  • Material 3에 Card(checked = …) 토글 오버로드가 없어서, Surface(checked = …)로 카드를 직접 조립한다. 카드의 색·모양·패딩을 손으로 다시 맞춰야 해서 버렸다.
그림자가 있는 카드가 생기면 첫 번째 방법은 그림자까지 잘라낸다. 그때는 세 번째로 옮겨야 한다.

플랫폼별 판정

물결은 Compose 가 그린다. 네 타깃 모두 같은 commonMain 코드가 돌고 플랫폼 API 차이가 없다.

플랫폼판정어떻게문서
Android구현공통 코드 그대로. 물결은 Compose 가 직접 그린다android.html
iOS구현공통 코드 그대로. Skiko 렌더링ios.html
JVM구현공통 코드 그대로. 포인터 hover 상태도 같은 모양으로 잘린다jvm.html
Web구현공통 코드 그대로. Canvas 에 그려서 CSS 와 무관하다web.html

한계

  • 물결의 모양은 자동 테스트로 가릴 수 없다. Compose UI 테스트는 시맨틱 트리를 보고, 물결은 애니메이션 중인 픽셀이라 시맨틱에 남지 않는다. 스크린샷 비교는 네 타깃의 렌더링이 서로 달라 기준 이미지를 네 벌 관리해야 해서 넣지 않았다.
  • 카드에 그림자(elevation)를 주면 클립이 그림자도 잘라낸다. 공통 구현의 결정 메모 참고.
