사용자 지시

홈 화면을 만들어라. 상단 카드에 앱 버전과 실행 중인 플랫폼을 보여주고, 그 아래 그리드에 기능 아이템을 나열한다. 첫 기능은 화면 꺼짐 방지 토글이다.

커밋 503bff1 "Add home screen with app info card and keep-screen-awake toggle"에서 복원. 원문 지시는 기록되지 않아 커밋 본문 기준으로 옮겼다.

처음 시작에 DeviceName이랑 DeviceId도 넣으면 좋겠어.

2026-09-25 대화. "처음 시작" 이 어디인지 되물었고 "앱시작 시 나오는 카드" 라는 답을 받았다 — 이 카드다. "DeviceName·DeviceId" 는 이 앱이 돌고 있는 기기(앱을 띄운 폰·시뮬레이터·Mac·브라우저)의 이름과 식별자로 읽었다. 기기 이름은 사용자가 이 기기를 다른 곳에서 찾을 때 쓰는 이름 — 데스크톱 기기 목록과 MCP device_list 가 그 기기를 부르는 이름 — 과 맞추기로 했다(결정). 그래서 Android 는 모델명, iOS 시뮬레이터는 시뮬레이터 이름·UDID 다.

요구사항

  1. R1. 카드에 앱 이름 "Jarvis", 앱 버전, 플랫폼 이름을 보여준다.
  2. R2. 앱 버전은 원본이 하나다. 화면, Android versionName, 데스크톱 packageVersion이 같은 값을 읽는다.
  3. R3. 플랫폼 이름은 어느 타깃에서도 비어 있지 않다.
  4. R4. 카드 아래에는 기능 그리드가 오고, 그리드는 창 너비에 따라 열 수가 바뀐다.
  5. R5. 카드의 플랫폼 줄 아래에 이 앱이 돌고 있는 기기의 이름("기기 이름")과 식별자("기기 식별자")를 한 줄씩 보여준다.
  6. R6. 기기 이름은 그 기기를 밖에서 부르는 이름과 같다 — Android 는 모델명(SM-X906N), iOS 시뮬레이터는 시뮬레이터 이름(iPhone 18 Pro Max), Mac 은 시스템 설정의 컴퓨터 이름. 기기 식별자는 그 기기에서 앱을 지우고 다시 깔아도 바뀌지 않는 값을 우선한다 — iOS 시뮬레이터는 UDID 라서 device_list 의 식별자와 같다.
  7. R7. Android·iOS·Web 과 macOS 데스크톱에서는 두 값이 비어 있지 않다. 값이 비어 있으면(macOS 밖 데스크톱) 그 줄을 그리지 않는다 — 빈 값을 보여주지 않는다.

한계

  • Android는 마케팅 버전이 아니라 API 레벨 정수를 보여준다. 마케팅 버전은 시스템이 제공하지 않는다.
  • Web은 브라우저 종류나 OS를 넣지 않는다. 필요하면 navigator.userAgent를 붙일 수 있다.
  • Android UI 테스트가 없어 R1·R5는 Android에서 컴파일로만 보장된다. 이유는 Android 테스트에 있다.
  • 기기 식별자는 device_list 의 식별자와 iOS 시뮬레이터에서만 같다. Android 의 adb 시리얼과 Android 에뮬레이터의 emulator-5554, 실물 iOS 의 UDID 는 앱이 읽을 수 없다(플랫폼 문서의 버린 후보).
  • 데스크톱은 macOS 에서만 값이 있다. 다른 OS 에서는 두 줄이 빠진다(R7).
  • Web 의 식별자는 브라우저 저장소(localStorage)를 지우면 새 값이 된다. 브라우저에는 기기 식별자 API 가 없다.
