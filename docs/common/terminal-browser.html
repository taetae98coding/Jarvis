터미널에서 웹 브라우저

그룹의 새 탭(+) 메뉴에서 "웹 브라우저" 를 고르면 그 그룹에 웹 페이지를 보여 주는 탭이 붙는다. 셸 탭과 같이 닫고, 끌어 놓고, 앱을 다시 켜면 마지막 주소로 다시 열린다.

사용자 지시

터미널에서 + 눌렀을 때 webBrowser도 지원해줘. 어차피 배포는 jvm은macOs만 지원할 생각이라 가장 간단하고 효율적인 방법으로 해줘.

2026-09-24 대화. "+" 는 그룹마다 있는 새 탭 버튼(분할 그룹)으로, "webBrowser 지원" 은 그 메뉴에서 웹 페이지를 띄우는 탭을 여는 것으로 읽었다. "가장 간단하고 효율적인 방법" 은 엔진을 앱에 싣지 않고 각 운영체제의 시스템 웹뷰를 쓰는 것으로 읽었다(결정).

요구사항

  1. R1. 새 탭(+) 메뉴의 항목은 위에서부터 "터미널", "Claude (YOLO)", "웹 브라우저" 다. 이 타깃에서 띄울 수 없는 항목은 빠진다. 남은 항목이 "터미널" 하나뿐일 때만 메뉴 없이 곧바로 셸 탭을 연다(Claude R6).
  2. R2. "웹 브라우저" 를 고르면 그 그룹의 탭 줄 끝에 브라우저 탭이 붙어 선택되고 그 그룹이 포커스를 받는다(셸 탭과 같은 자리·선택 규칙). 첫 페이지는 https://www.google.com 이다.
  3. R3. 브라우저 탭의 창은 위에 주소 줄, 아래에 웹 페이지다. 주소 줄은 뒤로, 앞으로, 새로 고침 버튼과 주소 입력칸이다. 뒤로·앞으로는 갈 곳이 없으면 잠긴다. 입력칸은 페이지가 바뀔 때마다 지금 주소를 보여 주고, Enter 를 누르면 입력한 곳으로 간다.
  4. R4. 입력은 이렇게 주소가 된다. 앞뒤 공백을 뗀다. :// 가 있으면 그대로다. 공백이 없고 localhost 로 시작하면 http:// 를, 공백이 없고 . 이 있으면 https:// 를 앞에 붙인다. 나머지는 Google 검색(https://www.google.com/search?q= 뒤에 UTF-8 퍼센트 인코딩)이다. 빈 입력은 아무 일도 하지 않는다.
  5. R5. 탭 이름은 페이지 제목이고, 제목이 없으면 "웹 N" 이다(N 은 탭 줄에서의 순서, 터미널 R13 과 같은 규칙). 제목은 저장하지 않는다. 가려진 탭은 이 화면에서 마지막으로 본 제목을 보이고, 화면을 나갔다 오거나 앱을 다시 켜면 다시 보일 때까지 "웹 N" 이다.
  6. R6. 페이지를 옮길 때마다 지금 주소가 탭에 저장된다. 앱을 다시 켜거나 가려졌던 탭이 다시 보이면 그 주소를 다시 연다. 뒤로 가기 기록, 스크롤 위치, 입력하던 폼은 남지 않는다.
  7. R7. 브라우저 탭은 셸을 띄우지 않는다. 닫기(✕), 끌어 놓아 분할·옮기기, 탭 고르기 단축키는 셸 탭과 같다. 브라우저 탭이 선택된 그룹을 ⌘D 로 나누면 새 그룹의 탭은 홈에서 시작하는 셸이다.
  8. R8. 웹 페이지를 띄울 수 없는 타깃(JVM 의 macOS 가 아닌 운영체제 포함)에서는 "웹 브라우저" 항목이 없다. 저장된 브라우저 탭이 있는 파일을 그런 타깃에서 열면 그 탭은 "[웹 페이지를 열 수 없습니다]" 만 보인다.
  9. R9. 새 탭 메뉴가 떠 있거나 탭을 끄는 동안에는 웹 페이지가 사라지고 그 칸이 비어 보인다. 메뉴가 닫히거나 탭을 놓으면 같은 페이지가 다시 보인다(새로 부르지 않는다). 메뉴와 놓을 자리 미리 보기가 페이지에 가려지지 않게 하려는 것이다(한계).
스코프에서 뺀 것
  • 북마크, 방문 기록 저장, 다운로드 관리, 개발자 도구, 탭 안의 새 창(target="_blank")을 새 탭으로 여는 것. 지시가 "가장 간단한" 브라우저다.
  • 브라우저 탭 단축키. ⌘T 는 셸 탭 그대로다.
  • 탭마다 쿠키·저장소를 나누는 것. 모든 브라우저 탭이 시스템 웹뷰의 기본 저장소를 함께 쓴다.
  • 가려진 탭의 페이지를 살려 두는 것(R6). 탭마다 웹뷰를 붙잡아 두면 셸 창처럼 앱 수명 동안 메모리를 쥔다. 다시 보일 때 저장된 주소로 새로 여는 쪽을 택했다.

공통 구현

도메인
TerminalProgram.Browser. TerminalTab.url: String? — Browser 탭에만 있다.
TerminalWorkspace.addTab(groupId, program = Browser, url = …), setUrl(tabId, url)(같으면 그대로).
browserAddress(input: String): String? — R4. 빈 입력은 null.
TerminalRepository.isBrowserSupported: Boolean, IsBrowserSupportedUseCase. OpenTerminalSessionUseCase 는 Browser 탭이면 저장소를 부르지 않고 null(R7)
공급
TerminalDataSource.isBrowserSupported. createTerminalDataSource 의 expect 시그니처는 그대로다. 저장 형식은 program = "browser" 와 url 키가 늘어난다. url 이 없는 browser 탭은 첫 페이지 주소로 읽는다
상태
TerminalViewModel.isBrowserSupported, addBrowserTab(groupId), setUrl(tabId, url). reconcile 은 Browser 탭의 셸 창을 열지 않는다. 페이지 제목은 저장하지 않고 창 안의 웹뷰 상태에서 바로 읽는다
UI
feature/terminal/ui/.../TerminalBrowser.kt — 주소 줄과 io.github.kdroidfilter.webview.web.WebView. 웹뷰 상태(rememberWebViewState)는 탭 id 로 key 를 건 컴포지션에만 있다. lastLoadedUrl 이 바뀌면 onUrl 로, pageTitle 이 바뀌면 탭 이름으로 올린다. pageHidden 이면 웹뷰의 크기를 0 으로 줄인다(R9). 이 값은 TerminalTabDragState.coversPages(끄는 중이거나 menuOpen)다
결정: 시스템 웹뷰를 감싼 composewebview(1.0.0-beta-02) 한 의존성으로 네 타깃을 덮는다 후보는 넷이었다. (1) JavaFX WebView 를 JFXPanel 로 넣기 — JVM 만 되고, macOS 한 곳만 해도 javafx-web·graphics·media 네이티브(WebKit 을 통째로 싣는다)가 번들에 수십 MB 붙는다. 페이지를 화면 밖에서 그려 Swing 이미지로 옮기므로 스크롤이 무겁다. 버렸다. (2) KCEF(JCEF, Chromium) — 처음 켤 때 100MB 넘는 Chromium 번들을 내려받는다. 버렸다. (3) JNA 로 WKWebView 를 AWT 창의 NSView 에 직접 붙이기 — 엔진은 시스템 것이라 가장 가볍지만 좌표·포커스·수명을 전부 손으로 맞춰야 하고 Android 는 따로 짜야 한다. 버렸다. (4) 채택: io.github.kdroidfilter:composewebview. Android android.webkit.WebView, iOS WKWebView, JVM 은 wry(Rust) 가 띄우는 시스템 웹뷰(macOS 에서는 WKWebView) 를 SwingPanel 로 넣는다. 엔진을 싣지 않아 번들이 작고, 공통 코드 한 벌로 끝난다. Compose 1.10 으로 빌드된 베타지만 이 프로젝트의 Compose 1.12.1·Kotlin 2.4.20 에서 JVM·wasmJs·iOS·Android 가 컴파일된다.
결정: 브라우저 탭도 TerminalTab 이다 탭 줄·끌어 놓기·닫기·저장이 전부 TerminalTab 을 단위로 돈다. 브라우저를 다른 모델로 두면 이 규칙들을 두 벌 짜야 한다. program 을 하나 늘리고 셸을 띄우는 두 곳(OpenTerminalSessionUseCase, TerminalViewModel.reconcile)과 창을 그리는 한 곳(TerminalGroup)만 갈랐다.

한계

  • 웹 페이지는 Compose 가 그리지 않는 네이티브 뷰라서 Compose 가 그리는 것이 그 위에 올라가지 못한다. 그래서 R9 대로 메뉴가 떠 있거나 탭을 끄는 동안 페이지를 치운다. 그동안 페이지가 보이지 않는다.
  • 페이지에 키보드 포커스가 있으면 키 입력이 네이티브 뷰로 바로 가서 터미널 단축키(⌘T, ⌘W, ⌘D, ⌘1–9 …)가 듣지 않는다. 주소 줄이나 다른 창을 누른 뒤에 쓴다.
  • R6 대로 탭을 옮기거나 다른 탭을 보다 돌아오면 페이지를 새로 연다.
  • 플랫폼마다의 한계는 각 플랫폼 문서에 있다.
