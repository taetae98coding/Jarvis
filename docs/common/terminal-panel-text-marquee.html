패널 줄 글자 흐르게

왼쪽 패널 목록 한 줄의 이름·브랜치·폴더 글자가 목록 폭을 넘으면 말줄임하지 않고 옆으로 끝없이 흘려(marquee) 글자 전체를 볼 수 있게 한다.

사용자 지시

왼쪽 사이드 탭 text들 basicMarquee Int.MAX_VALUE 적용해서 항상 모든 텍스트 볼 수 있도록 수정해줘.

2026-09-25 대화. "왼쪽 사이드 탭" 은 터미널 화면 왼쪽의 패널 목록(패널)으로, "text들" 은 패널 줄의 이름·브랜치 줄(워크트리)·폴더 줄(새 패널 제목·폴더)로 읽었다. "Int.MAX_VALUE" 는 Modifier.basicMarquee 의 iterations 로, 흐름이 세 번(기본값)에서 멈추지 않고 계속 되풀이되는 것이다. "항상" 은 hover·포커스·선택과 무관하게 흐르는 것으로 읽었다.

이 지시로 버튼을 아래 줄로 R2 의 "넘칠 때만 끝을 말줄임", 워크트리의 브랜치 줄과 새 패널의 폴더 줄의 "앞을 줄임(StartEllipsis)" 이 이 문서의 흐름으로 바뀐다.

요구사항

  1. R1. 패널 줄의 이름·브랜치 줄·폴더 줄은 각각 한 줄이고, 글자가 그 줄 폭보다 길면 말줄임(…) 없이 옆으로 흘러 글자 전체가 차례로 보인다.
  2. R2. 흐름은 멈추지 않고 되풀이된다(iterations = Int.MAX_VALUE). 화면에 들어오면 바로 시작하고 hover·포커스·선택 여부와 무관하다.
  3. R3. 줄 폭 안에 다 들어가는 글자는 움직이지 않고 이전처럼 왼쪽에 붙어 있다.
  4. R4. 세 줄은 저마다 따로 흐른다. 한 줄이 넘친다고 다른 줄이 움직이지 않는다.
  5. R5. 줄 높이·여백·색·글꼴, 선택 클릭, 버튼 줄, 이름 입력 필드는 이전과 같다.
스코프에서 뺀 것
  • 위쪽 탭 줄의 탭 이름(탭 종류 표시). 지시는 "왼쪽 사이드 탭" 이다.
  • 목록 맨 아래 "새 패널" 버튼 글자. 짧은 고정 글자라 넘치지 않는다.
  • 이름 입력 필드. 입력 중에는 커서를 따라 필드가 스스로 스크롤한다.
  • 가장자리 흐림(fade), 흐름 속도·쉼 조절. 지시에 없다. 기본값을 쓴다.
  • hover·포커스일 때만 흐르기. 지시가 "항상" 이다.

항목값
대상TerminalPanelItem 의 이름 Text, 브랜치 줄 Text, 폴더 줄 Text
흐름Modifier.basicMarquee(iterations = Int.MAX_VALUE). 나머지는 MarqueeDefaults: 속도 30dp/초, 한 바퀴마다(처음 포함) 1,200ms 쉼, 글자 끝과 다시 나오는 처음 사이 간격은 줄 폭의 1/3, MarqueeAnimationMode.Immediately
방향레이아웃 방향(왼쪽→오른쪽)대로 글자가 왼쪽으로 흘러간다. 시작 위치는 글자의 처음이다
글자maxLines = 1, overflow 는 지정하지 않는다(기본 Clip). 잘라내기는 marquee 가 줄 폭에서 한다
테스트 태그바뀌지 않는다

공통 구현

UI
feature/terminal/ui/src/commonMain/.../TerminalPanelList.kt 의 TerminalPanelItem — 세 Text 에서 overflow = TextOverflow.Ellipsis·StartEllipsis 를 걷고 Modifier.basicMarquee(iterations = Int.MAX_VALUE) 를 붙인다
상태
해당 없음. 모델·ViewModel 은 바뀌지 않는다
공급
해당 없음. expect 가 없다. basicMarquee 는 androidx.compose.foundation 1.12 의 안정 API 라 opt-in 이 필요 없다
결정: 말줄임을 걷는다 basicMarquee 는 자식을 너비 제한 없이(Constraints.Infinity) 재고 자기 폭에서 잘라 그린다. 그래서 Text 는 늘 글자 전체 폭으로 배치되고 overflow 가 끼어들 자리가 없다. 남겨 두면 읽는 사람이 말줄임이 된다고 오해하므로 지운다.
결정: 브랜치·폴더 줄의 "앞을 줄임" 을 흐름으로 바꾼다 StartEllipsis 는 끝(현재 브랜치·폴더 이름)을 늘 보여 주는 대신 앞을 숨겼다. 지시가 "항상 모든 텍스트" 라 흐름으로 바꾼다. 끝은 흐르는 동안 지나간다. 앞은 말줄임하고 hover 때만 흐르게 하는 안은 "항상" 과 맞지 않고 터치(Android)에 hover 가 없어 버렸다.

한계

  • 넘치는 줄이 있는 동안 그 줄은 매 프레임 다시 그려진다. marquee 가 글자를 자기 레이어에 그려 목록 전체는 다시 그리지 않지만, 긴 이름의 패널이 많으면 그만큼 계속 일한다.
  • 폴더·브랜치 줄의 끝(폴더 이름·현재 브랜치)이 늘 보이지 않는다. 흐름이 끝으로 갈 때까지 기다려야 한다.
  • basicMarquee 는 시스템의 애니메이션 줄이기 설정을 따르지 않는다(FixedMotionDurationScale). 설정을 꺼도 흐른다.
